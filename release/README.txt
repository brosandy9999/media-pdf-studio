========================================================================
                      MEDIA PDF STUDIO (PORTABLE)
                 Interactive Offline PDF & Audio Creator
========================================================================

How to Use on Any Windows PC:
1. Double-click 'MediaPdfStudio.exe'.
2. The Studio interface will automatically open in your default browser:
   (http://127.0.0.1:4173)
3. Open any PDF document.
4. Add your local MP3 audio files.
5. Place tiny ▶ play buttons anywhere on the PDF pages.
6. Reorder or fix page sequences with the '📑 Reorder Pages' tool.
7. Export your interactive PDF as an Offline Web Player (ZIP or Single HTML).

Features:
- 100% Offline (No internet or Python required to run).
- Touch Pinch-to-Zoom & smooth 2D horizontal/vertical panning.
- Dynamic inline seekbar on play/pause (disappears on stop).
- Media download and asset protection.
- Interchangeable 3-state playback (▶ Play ➔ Ⅱ Pause ➔ ■ Stop).

Requirements:
- Windows 10 / Windows 11 (64-bit).
- No installation needed — runs portably from any folder or USB drive.
